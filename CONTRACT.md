# Internal integration contract

Python standard library only; Windows primary platform, Python 3.10+. Package `engineer`.

Telemetry `engineer/telemetry.py`: `ACReader.read() -> dict | None`, `close()`. Safe missing-game behavior; frames status is live/paused/replay/menu. `DemoSource.read() -> dict` deterministic time-based driving demo, method `reset()` if useful. Public normalized frames use `timestamp` (Unix seconds), `source` (`live`/`demo`), `status`, `car_id`, `track_id`, `layout`, `driver`, `packet_id`, `speed_kmh`, `rpm`, `gear` (display R/N/1 etc string), `gas`, `brake`, `steer` (normalized input), `fuel_l`, `lap_count`, `lap_time_ms`, `last_lap_ms`, `lap_valid` (bool or null), `normalized_pos`, `track_length_m`, `in_pit`, `wheels_out`, `surface_grip`, `ambient_c`, `road_c`, `tyre_compound`, `tyre_pressure_psi` (FL FR RL RR), `tyre_core_c`, `tyre_inner_c`, `tyre_middle_c`, `tyre_outer_c`, `tyre_wear_raw`, `wheel_slip`, `local_velocity`, `local_angular_velocity`, `acc_g`, `abs`, `tc`, `brake_bias`, `kers_charge`, `ers_power_level`, `ers_recovery_level`, `has_ers`/`has_kers`, `drs`, `capabilities` (dict), `warnings` list. Unknown signals use null, not fabricated values. More fields okay.

Analysis `engineer/analysis.py`: `Engineer(data_dir: pathlib.Path)`, `.update(frame: dict) -> dict`, `.snapshot() -> dict`, `.configure(settings: dict)`, `.reset()`. `.update` returns full analysis snapshot. Snapshot keys: `laps` (recent records), `reference` (dict or null), `corners` (list), `messages` (list with id, text, severity, kind, timestamp), `fuel` (dict), `coaching` (dict), `setup` (list), `traces` (dict or list), `session` (dict). Core owns recording and persistence. Record only live status, separate demo/live identity. Numeric rules, same car/track reference, reject incomplete/out/invalid/pit laps. Settings include `focus` (balanced/stability/rotation), `fuel_reserve_l` (default 2), `target_pressure_psi` (null default), `voice` boolean.

Companion HTTP at 127.0.0.1:8777 (root owns server). GET /api/state returns `{connected, mode, telemetry, analysis, settings, voice, version}`. GET /api/overlay returns compact text lines `{connected, mode, title, lap, delta, fuel, tyres, advice, severity}`. GET /api/health -> okay. POST /api/action JSON with action: demo/live/mute/radio/reset/stop; POST /api/settings settings object. POST /api/bridge optional game timing data. Origin/Host local-only checks for mutations. UI has demo/live explicit; never silently fall back to demo.

AC Python in-game app (agent owns `ac_app/` only): standard AC Python 3.3 compatible, no external dependencies. Poll /api/overlay off render thread with urllib, update labels only on render thread. GET is local loopback only. AC app name RaceEngineer; show disconnected status/instructions; enable via CM. May POST race-wide timing to /api/bridge off thread. No game setup/control mutation.

Root owns `app.py`, `engineer/voice.py`, `web/`, Windows launch/install scripts, README, packaging. Agents own tests for their modules, root handles integration tests. Do not overwrite other agents' files.
