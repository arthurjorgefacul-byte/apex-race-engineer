# APEX 0.5.1 playtest

This update adds the APEX racing-line monogram to the application header, window and executable icon. The logo is embedded in the app and does not depend on an external image folder at runtime. Production SVG, transparent PNG and Windows icon exports are provided separately in the brand kit.

A fresh installation now opens with the APEX local engineer. Existing saved engine choices are preserved; AC Pro Engineer remains available in Settings.

The shareable playtest pack includes a short setup guide, a 20-minute testing checklist, a copyable invitation and a feedback template. It excludes personal recordings, settings and logs. Testers still need the documented Windows runtimes and their own original Assetto Corsa/CM/CSP installation. Voice input additionally needs Windows English (United States) speech recognition. There is no automatic dependency installer or requirements checker in this build.

Racing analysis and live engineer behavior are unchanged from 0.5. See [0.5 release and validation notes](RELEASE_0.5.md) for capabilities and limits. This is a playtest build, not a claim of acceptance on every wheel, mod or tester PC.
